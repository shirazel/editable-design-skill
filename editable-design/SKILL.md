# עיצוב עם עורך מובנה

המטרה: המשתמש מקבל עיצוב מוכן, ויכול לתקן אותו לבד בדפדפן, בלי לחזור לשיחה על כל מילה או מספר.

כל גרפיקה יוצאת בשני קבצים:
1. **תמונה מוכנה (PNG)**, לשליחה מיד.
2. **קובץ עריכה (HTML)**, שנפתח בכרום או באדג' וכולל את כל הכלים.

## סדר העבודה

1. **מעצבים כרגיל ב-HTML**, לפי המיתוג של המשתמש אם יש לו. כל העיצוב בתוך אלמנט אחד:
   ```html
   <div id="design"> ... </div>
   ```
   ל-`#design` נותנים ב-CSS רוחב וגובה קבועים (למשל 1080x1350 לפוסט, 1080x1920 לסטורי, 1080x1080 לריבוע), `position:relative`, `overflow:hidden` ורקע. לא שמים את המידות על `body`.
2. **טקסט שאפשר לערוך:** כותרות ופסקאות (`h1` עד `h6`, `p`, `li`) נעשות ניתנות לעריכה לבד. לכל טקסט אחר (תאריך, מחיר, כיתוב כפתור) מוסיפים `data-edit`. לחלק שאסור לגעת בו מוסיפים `data-noedit`.
3. **חלקים שאפשר לגרור:** טקסט, תמונות ו-SVG נגררים לבד. לכרטיס או קבוצה שלמה מוסיפים `data-move`.
4. **תמונות:** ההורדה כתמונה משתמשת ב-html2canvas, שלא מכיר `object-fit`. לכן חותכים כל תמונה מראש בדיוק לגודל המסגרת שלה (למשל PIL `ImageOps.fit`, פי 2 לחדות).
5. **צילום PNG** של העיצוב בגודל המדויק (puppeteer או Chrome headless), ושמירה בשם ברור.
6. **בניית קובץ העריכה:**
   ```
   python scripts/make_editable.py design.html "עריכת-<שם>.html" --key <שם-ייחודי-באנגלית> --file "<שם>.png"
   ```
   הסקריפט מטמיע את התמונות בתוך הקובץ ומוסיף את העורך (`assets/editor.css`, `assets/editor.js`, html2canvas מ-cdnjs). אם אין אפשרות להריץ Python, עושים אותו דבר ידנית: מדביקים את התוכן של `editor.css` בתוך `<style>`, ובסוף `body` טוענים את html2canvas ומדביקים את התוכן של `editor.js` בתוך `<script>`.
7. **בדיקה לפני מסירה:** פותחים את קובץ העריכה, מריצים `html2canvas(document.getElementById('design'))` ומשווים לצילום ה-PNG. אם יש הבדל, מתקנים לפי המלכודות למטה.
8. **מסירה:** שולחים את ה-PNG ואת קובץ העריכה, ומסבירים בקצרה: לחיצה כפולה על הקובץ פותחת אותו בדפדפן, והכפתורים נמצאים בפס העליון.

## מלכודות ידועות

- **אסור כלל CSS כללי על `img`** (למשל `img{position:absolute}`). html2canvas משתמש בתמונה פנימית כדי למדוד טקסט, וכלל כזה מעלים את כל הטקסט מהתמונה שיורדת. מעצבים תמונות דרך class בלבד.
- `text-decoration: line-through` לא מצויר בהורדה. מחיר מחוק עושים עם `::after`: קו במיקום absolute באמצע הגובה.
- `object-fit` לא נתמך. חותכים את התמונות מראש.
- לא שמים `border-radius` על `[contenteditable]`, כי זה דורס את העיגול של כפתורים.
- בעברית, מספר שצמוד למילה עלול להתהפך ("מ-29.10" נראה כמו "29.10-מ"). משתמשים במקף עברי `־` (מ־29.10).
- משאירים מקום לטקסט להתארך. משתמשים נוטים להאריך טקסטים בעורך, ולכן בודקים את העיצוב עם טקסט ארוך פי 1.5.
- **כשמעדכנים קובץ עריכה שהמשתמש כבר עבד בו:** השינויים שלו שמורים בדפדפן לפי ה-`--key` וה-`data-v`. שינויי CSS בלבד עוברים אליו בלי לפגוע בטקסטים. לא משנים את המבנה (HTML) בלי לשאול.

## כשהעריכה התבלגנה: "שליחה לקלוד"

כשטקסטים יוצאים מהמסגרת או נוצרו כפילויות, לא מתקנים בעיוורון:
1. מבקשים מהמשתמש ללחוץ **"שליחה לקלוד"** בעורך. יורד קובץ `<key>-edit-for-claude.html` עם כל הטקסטים, הגדלים וההזזות (בלי תמונות). המשתמש מעלה אותו לשיחה, או אומר איפה הוא נשמר.
2. בונים את העיצוב מחדש בקובץ המקור עם הטקסטים שלו, בגדלים שנכנסים. מראים PNG ומחכים לאישור.
3. אחרי האישור מעלים את `data-v` של `#design` באחד ובונים מחדש את קובץ העריכה. כך הדפדפן טוען אוטומטית את הגרסה החדשה, והעריכה הקודמת נשארת שמורה במפתח הישן. מספיק לרענן (F5).

## שמירה, פרויקטים ומשתמשים אחרים

- כל קובץ עריכה שומר בנפרד, לפי ה-`--key` שלו. עיצוב אחד לא נטען לתוך אחר, כל עוד לכל עיצוב יש מפתח ייחודי. לא נותנים לשני עיצובים אותו מפתח.
- השמירה נמצאת בדפדפן ובמחשב של מי שעורך. מי שמקבל את קובץ העריכה ופותח אותו אצלו רואה את העיצוב המקורי. כדי להעביר את הגרסה הערוכה, שולחים את ה-PNG, או בונים קובץ חדש מתוך "שליחה לקלוד".

## מה יש בעורך (להסבר למשתמש)

הפס העליון:
- **מצב הזזה**: כשהוא דולק גוררים כל חלק בעכבר. כשהוא כבוי לוחצים על טקסט וכותבים.
- **+ הגדלה / - הקטנה**: גודל הטקסט שנבחר. **עובי הכתב**: רגיל, בינוני, מודגש, מודגש מאוד.
- **+ טקסט חדש**, **שכפול** (עותק באותו עיצוב, מתחת למקור), **מחיקה**, **ביטול פעולה**.
- **שמירה** (יש גם שמירה אוטומטית אחרי כל שינוי), **חזרה למקור**.
- **שליחה לקלוד**: מוריד קובץ קטן עם העריכה, כדי שקלוד יסדר את העיצוב בקוד.
- **הורדת תמונה**: שומרת PNG בתיקיית ההורדות.

אם העורך נפתח בשתי לשוניות, הלשונית הישנה ננעלת כדי לא לדרוס שינויים. כשמוחקים את כל הטקסט בתיבה, התיבה נעלמת, וביטול פעולה מחזיר אותה. הדבקה מכניסה טקסט נקי, בלי עיצוב.

## בצ'אט הרגיל (claude.ai)

בונים קובץ HTML אחד: העיצוב, התוכן של `editor.css` ו-`editor.js` מודבק בתוכו, ותמונות מוטמעות כ-data URI. מוסרים אותו **כקובץ להורדה**, לא רק כ-artifact בתוך הצ'אט, כי בתוך חלון הצ'אט השמירה וההורדה עלולות לא לעבוד. המשתמש מוריד את הקובץ ופותח אותו בכרום, ושם הכל עובד.
